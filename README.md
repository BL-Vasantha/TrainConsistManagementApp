# 🚆 Train Consist Management App

> A console-based Java application to simulate railway train consist operations using real-world railway scenarios and Java concepts.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 🌟 Overview

The **Train Consist Management App** manages a train consist (collection of bogies attached to an engine) and demonstrates **Core Java, Collections, Streams, Algorithms, Exception Handling, Regex, and Performance Optimization**.

Each Use Case (UC) introduces concepts progressively through practical implementation.
